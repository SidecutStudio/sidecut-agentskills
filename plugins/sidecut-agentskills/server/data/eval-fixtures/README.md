# Eval fixtures

The JSON files and schema are vendored verbatim from commit `df8c7a3a1cb5b372803ef4d26aed3463a227c60d`. Each case provides a user prompt and grading criteria. Some also provide workspace files or describe simulated context.

Agentskills generates the starter routing cases from the status and notes pairs. The generated graders check skill invocation. Use the original fixture when you need to test the outcome or set up its simulated context.
